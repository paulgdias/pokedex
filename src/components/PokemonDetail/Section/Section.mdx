# Section

A titled card that groups one part of the detail page. `InfoSection` (a named export of the same file) wraps it for content that needs the lazily fetched pokémon info and shows a loading or error state until `data` arrives.

## Behaviour

- The `title` is the section's heading and its accessible name (`aria-labelledby`).
- `InfoSection` takes the info query and a render function for the loaded content.
