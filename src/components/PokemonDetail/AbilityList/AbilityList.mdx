# AbilityList

A pokémon's abilities with their effect text, on the detail page. Hidden abilities get a "Hidden" badge.

## Behaviour

- Names are formatted with `formatName` (`overgrow` → `Overgrow`).
- The effect line is omitted when there is no effect text.
