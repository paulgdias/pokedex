# TypeMatchups

Damage multipliers against a pokémon's type combination, grouped by multiplier (4×, 2×, ½×, ¼×, 0×). The chart comes from `typeEfficacyQueryOptions`.

## Behaviour

- Dual types multiply: grass × poison resists grass twice over.
- Neutral (1×) matchups are left out.
- Screen readers hear "Damage taken:" before each multiplier, not a bare number.
