# InfoFacts

Size, breeding and species facts as a definition list: height, weight, base experience, capture rate, base happiness, gender, egg groups, growth rate, habitat, color and shape.

## Behaviour

- Missing values show an em dash.
- Gender is a bar of the female / male share, or "Genderless".
