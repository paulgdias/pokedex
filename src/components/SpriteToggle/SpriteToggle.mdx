# SpriteToggle

An "Artwork" / "In-Game" segmented control (react-aria `ToggleButtonGroup`) overlaid on the bottom-right of the detail page's large card. "In-Game" is the 96px pixel sprite, drawn by `PokemonCard` with `pixelated`.

## Behaviour

- Absolutely positioned over the card's art, so it needs a positioned parent.
- Exactly one option is always selected (`disallowEmptySelection`).
- "In-Game" is disabled when the pokémon has no pixel sprite (`isInGameAvailable={false}`).
