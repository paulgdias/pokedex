# SectionLabel

The small, bold, uppercase, letter-spaced label that names a group of content: a detail-page section ("Abilities"), an evolution lane, or a type-chart column ("Fire attacking").

## Behaviour

- Renders a `div` by default. Use `as="h2"` or `as="h3"` when it is the heading that names a section, and pass `id` to label that section.
- `span` is available for inline use.
- `className` is merged with `twMerge`.
