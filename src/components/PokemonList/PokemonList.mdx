# PokemonList

The card grid: a virtualized `react-virtualized` `Grid` inside an `AutoSizer`. Column and row math lives in `getPokemonGridProps` (`PokemonList/utils.ts`).

## Behaviour

- Only cards near the viewport are mounted.
- Scrolls back to the top whenever `pokemon` changes.
- `scrollToPosition` (default on) shows a `ScrollTopButton` that scrolls the grid to the top; pass `false` to leave it out.
- `isLoading` renders `PlaceholderCard`s instead of `pokemon`.
- Clicking a card navigates to its page and passes `previous` in router state, so back navigation returns to the same filters.
