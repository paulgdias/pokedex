# PokemonTable

The list view: a virtualized table (`react-virtualized` `List`) with sortable column headers, type dots and the six base stats plus total. The stat columns are hidden below the `md` breakpoint.

## Behaviour

- Semantics: `table` > `rowgroup` > `row` > `cell`. The active column header has `aria-sort`.
- Pressing a header sorts by it; number columns start with the highest, and pressing the active one flips the direction.
- The name link is stretched over the whole row.
- Scrolls back to the top when the list changes.
