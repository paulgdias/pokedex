# EvolutionChain

The evolution chain on a pokémon's detail page: compact cards in stages joined by arrows, with the trigger (`Lv. 16`, a stone, friendship...) as a pill on each arrow. Data comes from `buildEvolutionLanes` in `@utils/evolution`.

## Behaviour

- The current pokémon has the accent border and `aria-current`; it is not a link. Every other card navigates to that pokémon.
- Mega and Gigantamax forms sit in a dashed "Other forms" box; each regional variant (Alola, Galar, ...) gets its own lane.
- Stacks vertically below the `md` breakpoint.
- Renders nothing for a pokémon with no evolutions and no alternate forms.
- Navigation passes `previous` in router state so the back button returns to the same list filters.
