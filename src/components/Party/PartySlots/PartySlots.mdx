# PartySlots

The party on the Party Analyzer page: a list of exactly six `PartySlot`s in a grid, two columns below `md` and three from `md` up.

## Behaviour

- `party` always has six entries; `null` is an empty slot.
- `onSet(index, id)` fills a slot and `onSet(index, null)` clears it. The component holds no party itself; the page writes it to the `party` URL param.
- Every empty slot's picker leaves out the Pokémon already in the party.
