# SlotPicker

The search box of an empty party slot, built like the Compare page's picker: a react-aria `ComboBox` whose suggestions come from `getPokemonSuggestions` (`@utils/search`).

## Behaviour

- Labelled "Slot N Pokémon", with N the slot's position (`index + 1`).
- Typing a name or dex number lists up to eight matches, each with its sprite, `#0001`-style number and name. Pokémon in `excludedIds` (the rest of the party) are never offered.
- Picking one calls `onSelect(id)` and clears the text.
