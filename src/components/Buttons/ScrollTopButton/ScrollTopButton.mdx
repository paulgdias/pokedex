# ScrollTopButton

A round button fixed to the bottom-right corner that scrolls the page back to the top. It is built on the react-aria `Button`, so it responds to click, tap, Enter and Space.

## Behaviour

- Labelled "Go to Top of Page" for assistive tech; the arrow icon is decorative.
- Only calls `onPress`; the caller decides what to scroll (see `PokemonList`).
