# ThemeToggle

A Light / System / Dark control managed by `useTheme` (`@utils/useTheme`). It sits in the sidebar and the mobile top bar and uses the sidebar tokens, which are the same in both themes.

## Behaviour

- Takes no props.
- The choice is saved in `localStorage` under `theme` and applied as `data-theme` on `<html>`; "System" follows the OS setting.
