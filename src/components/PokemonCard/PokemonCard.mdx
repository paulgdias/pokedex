# PokemonCard

A pokémon's card: official artwork with a dex number watermark, type pills and a Legendary / Mythical badge. It is used in the grid, and at `size="large"` as the detail page's hero card.

## Behaviour

- With `navigateCallback` the card is a focusable link: click or Enter calls it with the event and the pokémon. Without it the card is static (not focusable, no pointer cursor).
- The artwork is preloaded with `fetchPriority: "high"`.
- `sprite` replaces the artwork (the detail page uses it for the in-game sprite); `pixelated` renders it crisply at a whole-number scale.
- `children` render as an overlay in the art area (the detail page puts `SpriteToggle` there).
- Mythical wins if both `isMythical` and `isLegendary` are set.
- A pokémon without artwork shows its dex number in place of the image.
