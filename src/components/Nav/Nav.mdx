# Nav

App navigation: a sidebar on desktop and a compact top bar below the `lg` breakpoint. It holds the logo, the page links (Home, Pokédex, Compare, Type chart), the theme toggle and the generation links with per-generation counts.

## Behaviour

- Takes no props. It reads the dex with `useRouteLoaderData` (route ids `"pokedex"` and `"pokemon"`), so it needs a data router around it.
- Both the sidebar and the top bar are in the DOM; CSS shows one of them.
- The link to the current page keeps the query string; links to other pages do not.
- Generation links only apply filters on the list page, not on a single pokémon's page.
